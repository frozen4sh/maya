Maya

For a video on how to use this tool please visit: http://www.madguru.com/support

Basically, pose either the ik or fk limb of your choice. Switch to the type (ik or fk) that you want to match to that pose using the + switcher for that limb. Set auto key on if you like. Select a rotation, ik or pole vector control for that limb, then click the IKFK Match tool button from the shelf to run the script. The limbs should be matched for a smooth transition between ik and fk or vice versa.
